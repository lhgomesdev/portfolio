## Sobre

Site estático de página única (single page), sem frameworks front-end e sem build step — só HTML, CSS e JavaScript puros. Alterna entre português e inglês via um sistema de i18n simples em JS.

## Stack

- HTML5
- CSS3 (variáveis nativas, sem pré-processador)
- JavaScript (vanilla, sem dependências de build)
- [Phosphor Icons](https://phosphoricons.com/) (via CDN)
- Fontes: [Fira Code](https://fonts.google.com/specimen/Fira+Code) e [Inter](https://fonts.google.com/specimen/Inter) (Google Fonts)
